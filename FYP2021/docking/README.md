# Inhibitor design project 2021

Since the project is related to a part of the unpublished work of our group,  not all the files of the hands-on exercise would be included here.

Only modified scripts and tutorial notes that use other Biomolecular systems is provided here.

This is a one-semester (6 months) individual project. The project includes 
- literature review, 
- two progress reports and one final thesis required by the department 
- research planning, 
- hands-on experience on molecular docking via the UCSF Chimera GUI of AutoDock Vina, 
- introduction to MD simulation with demonstration session done by the mentor using the complex selected by the student.
