Quick Guide
-----------
* GROMACS input preparation
	- Refer to GROMACS tutorials and documentation for detailed explanation
	- CHARMM-GUI input generator (e.g. solution builder to build solvated protein system) is a useful
	  tool to generate GROMACS inputs. You can find the URL in the "Suggested Softwares/Web service"
	  section below.
	- Notes on the files generated by CHARMM-GUI:
		-> You should carefully inspect and do the necessary modifications (using e.g. Notepad) in the 
		   generated files, especially those hightlighted in "NotesOnCharmmGUI.png" within the 
		   "gromacs" subdirectory. Specifically:
				> In the .mdp files modify the "nsteps" to change the simulation length
					Default value: 
						Energy minimization	|	5000 steps Steepest Descent
						NVT equlibration	|	125000 steps with dt=0.001 (125 ps)
						Production run		|	500000 steps with dt=0.002 (1 ns) 
									|	[Using the while-loop in the README csh: 10 runs x 1 ns = 10 ns]
				> The "README" file is actually a CSH script with gromacs commands. You can substitude the 
				  "gmx" and "gmx_d" with \WHERE\YOU\PUT\THIS\FOLDER\gmx_fftw3_cpu_omp\bin\gmx.exe, change the variables in
				  the commands within the while-loop, then open the command prompt/PowerShell WITHIN THIS
				  "gromacs" DIRECTORY and copy-and-paste the commands to run the simulations. 
				  ***DO NOT RUN IT DIRECTLY UNLESS YOU HAVE CSH OR TCSH SHELLS!!!***
		-> You still need to write your own commands for analysis.
		-> If you would like to use "simulation_template.cmd", please refer to the example below.

* MD simulation with GROMACS: 
	1. Navigate to the folder with your input file.
	2. Open the folder with the command prompt or Windows PowerShell
	3a. Use the command line to call gromacs with the full path
		- Please refer to the GROMACS documentation and online tutorials, or check 
		  t1-auto-win.cmd (with e.g. Notepad) for sample usage of GROMACS commands
		- If you use the files generated by CHARMM-GUI, you may try to use simulation_template.cmd following the instructions below.
	3b. Example of using CHARMM-GUI files with "simulation_template.cmd" for a 10ns NPT simulation
		Steepest descent EM -> 125 ps restrained NVT -> 500 ps restrained NPT -> 10/5/2/1 ns NPT
		i) Download and extract the files generated by CHARMM-GUI
		ii) Navigate to the gromacs directory
		iii) COPY "step5_production.mdp" to "step4.2_equilibration.mdp"
		iv) Modify "step4.2_equilibration.mdp" with Notepad:
			- Copy the first line of "step4.1_equilibration.mdp" (define....) to the top of this file
			- Change the value of nsteps to 250000
			- Optional: change the value of nst"xxx"output to control output frequency
		v) Modify "step5_production.mdp" with Notepad:
			- Change the value of nsteps to 5000000 (for 10ns simulation)
							2500000 (for 5ns simulation)
							1000000 (for 2ns simulation)
							500000 (for 1ns simulation)
			- Optional: change the value of nst"xxx"output to control output frequency
		vi) COPY "simulation_template.cmd" to this gromacs directory
		vii) Modify "simulation_template.cmd" with Notepad:
			- Line 14: SET GMXPATH=\LOCATION\OF\GMX.EXE\
				Replace \LOCATION\OF\GMX.EXE\ with the correct path
		viii) Double-click the "simulation_template.cmd" you just modified and wait.
		
		
*Ploting the graphs in .xvg files:
	1. Drag and drop the .xvg files to the QtGrace shortcut

Source and other info. of the contents in this zip file
-------------------------------------------------------
* doc
	1. Gromacs manual: http://manual.gromacs.org/documentation/2019.6/manual-2019.6.pdf
	2. MD Basics: https://www.livecomsjournal.org/article/5957-best-practices-for-foundations-in-molecular-simulations-article-v1-0
	3. MD Tutorial: https://livecomsjournal.org/index.php/livecoms/article/view/v1i1e5068

* GROMACS 2019.6
	1. Source code: ftp://ftp.gromacs.org/pub/gromacs/gromacs-2019.6.tar.gz
	2. FFTW3 library was compiled on Windows 10 with MinGW64 using a modified version of BUILD-MINGW64.sh
		(ftp://ftp.fftw.org/pub/fftw/BUILD-MINGW64.sh) with the --enable-avx2 option added
	3. Compiled on Windows 10 with Microsoft Visual Studio 2019 (Developer PowerShell) using the following commands:
		& '\PATH\TO\VISUAL\STUDIO\2019\INSTALLATION\VC\Auxiliary\Build\vcvars64.bat'
		cmake .. -DFFTWF_INCLUDE_DIR="/PATH/TO/FFTW3/INSTALLATION/fftw-3.3.8-dll64" -DFFTWF_LIBRARY="/PATH/TO/FFTW3/INSTALLATION/libfftw3f-3.lib" -DGMX_GPU=OFF -DGMX_BUILD_SHARED_EXE=OFF
		cmake --build . -v --config RELEASE -j 8
		cmake --install . --prefix /PATH/TO/GROMACS/INSTALLATION/DIRECTORY/
	4. Copying libfftw3f-3.dll to the Gromacs bin directory.
	5. Copying VC++ redistributables into the Gromacs bin directory
		To make it portable, VC++ 2015 redistributables are provided in "local deployment" mode within the bin directory of gromacs, as explicitly allowed by [Microsoft's Deployment in Visual C++](https://learn.microsoft.com/en-us/cpp/windows/deployment-in-visual-cpp?view=msvc-140) (see [this page](https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files?view=msvc-140) for details).
		
* QtGrace
	1. Binary distribution downloaded from https://sourceforge.net/projects/qtgrace/

* Jmol
	1. Downloaded from https://sourceforge.net/projects/jmol/
	2. Removed JSMol.zip to reduce filesize.
	3. You need the Java runtime installed on your computer to use Jmol.
	4. To visualize MD trajectories in Jmol, covert .xtc files into .pdb format using "gmx.exe trjconv" tool.
	5. For a better GUI of viewing and analyzing trajectories, get UCSF Chimera or VMD.

*tutorial_1_auto
	1. Automatically run the commands from the first tutorial writtern by Dr Justin Lemkul. Website: http://www.mdtutorials.com
	2. Publication of the tutorial suite DOI: 10.33011/livecoms.1.1.5068
	3. Detailed description can be found in at the begining of t1-auto-win.cmd

*simulation_template.cmd
	Modified from the csh script generated by CHARMM-GUI to be run with Windows cmd.
