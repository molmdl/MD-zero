# Docking tutorial for UG students from experimental group

Demo files came from the official website of [AutoDock](http://autodock.scripps.edu/faqs-help/tutorial/using-autodock-4-with-autodocktools) which is no longer available as of May 2023. The PDF of the tutorial can still be found in [other site](https://dasher.wustl.edu/chem430/software/autodock/tutorial-hiv-protease.pdf) on the internet.

Instead, the developers of AutoDock recommend the use of more updated materials. Please refer to the new [AutoDock website](https://ccsb.scripps.edu/projects/docking/) for details.

The actual hands-on exercise done by the students involved the use of unpublished data from the experimental group, thus the input and details would not be provided in this directory. PPT was modified accordingly.
