# Introductory exercise on homology modelling and MD simulation for experimental researchers

The actual hands-on exercise involved the use of unpublished data from the experimental group. Thus the input files would not be provided in this directory. Slides have been modified accordingly.

The PPT was adjusted according to the lesson each supervisor would like to deliver to their students.

Highlighted methodology:
- Protein data taken from UniprotKB and the RCSB PDB.
- Homology modelling heavily relied on the BLAST interface and MODELLER interface in UCSF Chimera. Validation method modified from [the free online tutorial provided by the Brown Lab](<https://osf.io/82n73/wiki/Homology Modeling and Validation>)
- MD protocol and input scripts were taken from [Dr Justin Lemkul's GROMACS tutorial](http://www.mdtutorials.com/gmx/index.html).
- Detailed reference can be found in the PPT file.
